## Как проверить

```
go vet ./...
go test ./...
bash scripts/check_secrets.sh
```

Контрольная репетиция (уже выполнена, сеть и ключ нужны только для повтора):

```
CONTROL_OUT=out/s14-rehearsal SUBMISSION_DIR=out/s14-submission \
  bash scripts/control_run.sh testdata/rehearsal/articles.json "2026-11-07T12:00:00+03:00"
```

Повтор и инъекция:

```
go run ./cmd/digest run --dataset testdata/rehearsal/articles.json --control-time "2026-11-07T12:00:00+03:00" --out out/s14-extra-repeat --extra testdata/rehearsal/extra-repeat.json
go run ./cmd/digest run --dataset testdata/rehearsal/articles.json --control-time "2026-11-07T12:00:00+03:00" --out out/s14-extra-inject --extra testdata/rehearsal/extra-inject.json
```

Если в окружении остались пустые `LLM_PROXY` и `LLM_PROXY_FILE`, их нужно удалить до запуска, иначе `.env` их не перекроет.
