# S1: Загрузка и нормализация набора

Владелец: A
Статус: выполнен
Ветка / коммит: s1-ingest / S1: load and normalize datasets

## Сделано

- `ingest.LoadDataset` читает JSON (массив и объект с массивом), JSONL, CSV с разделителями `,` и `;`, каталог и одиночный текстовый файл.
- Кодировки: BOM UTF-8 и UTF-16, UTF-16 без BOM по устойчивому шаблону, иначе UTF-8, иначе windows-1251 или koi8-r по русским биграммам (`golang.org/x/text` v0.28.0).
- Поля берутся из `config.ingest.field_map`, при отсутствии колонки используются алиасы (`body`, `content`, `published`, `date`, `pub_date` и другие). Маркеры `missing_markers` попадают в `MissingFields`.
- Пустой файл, битый JSON, пустая запись и запись без ID не роняют загрузку. Для записи без ID выдается `unknown-N`. Дубль ID остается в журнале с `duplicate_id`, в статьях хранится первая запись.
- `normalize.Clean` снимает HTML, нулевые и управляющие символы, схлопывает пробелы и сохраняет абзацы. `normalize.Apply` оставляет `RawText` и заполняет `SourceKind`.
- `normalize.Chunks` режет длинный текст по абзацам и предложениям с перекрытием и не разрывает числа и даты.
- Реестр источников приложения 1 лежит в `internal/ingest/sources.go`.
- Синтетика: `testdata/synthetic/articles.json`, 40 записей, контрольное время `2026-11-07T12:00:00+03:00`. Описание каждой записи в `testdata/synthetic/README.md`.
- Трудные входы: `testdata/hard/` (пустой файл, битый JSON, BOM, windows-1251, koi8-r, UTF-16, нулевые байты, статья больше 1 МБ, дубли, JSONL с битой строкой, каталог).

## Как проверить

```
go test ./internal/ingest/... ./internal/normalize/...
make vet test
```

Загрузка `testdata/synthetic/articles.json` возвращает все 40 ID. Файлы из `testdata/hard/` не дают ошибки загрузчика.

## Нюансы для следующих этапов

- `PublishedAt` загрузчик не заполняет. Строка даты лежит в `PublishedRaw` (пробелы по краям сняты). Разбор и фильтр периода делает S2.
- Успешные записи возвращаются только в `[]Article`. Журнал загрузки содержит проблемные: `empty_input`, `read_error`, `duplicate_id`.
- Запись без ID есть и в статьях (`unknown-N`, `ReadError` = «нет идентификатора»), и в журнале. Ее не надо проводить как обычный материал и не надо заводить вторую причину.
- Дубль: первая запись в статьях, следующая строка журнала с тем же ID. В итоговом журнале это две строки набора с одним ID.
- Пустой файл, битый файл и пустой массив получают `unknown-N`. Счетчик общий на один вызов `LoadDataset`.
- В каталоге пропускаются скрытые файлы, `README.md` и `README.txt`. Обычный `.txt`, `.html`, `.md`: ID из имени файла, заголовок из первой строки, остальное в тексте.
- `normalize.Apply` нужно вызывать до тематической модели: `Text` очищен, `RawText` исходный. Повторный вызов не портит `RawText`.
- `Chunks(text, maxChars)` перекрывает соседние куски примерно на `maxChars/5` рун (не больше 400). Кусок может быть длиннее лимита, если иначе пришлось бы разрезать число или дату.
- Одиночный перенос строки при чистке становится пробелом, пустая строка остается границей абзаца.
- `source_kind` ставится и при загрузке, и в `normalize.Apply`.

## Изменения контрактов

Нет. `internal/domain`, `internal/config`, `config.yaml` и `Makefile` не менялись.

В `go.mod` добавлен `golang.org/x/text` v0.28.0. Версия v0.29.0 поднимает директиву Go до 1.24, поэтому взята последняя, которая остается на Go 1.23.

## Открытые вопросы

- Формат набора организаторов по-прежнему неизвестен. Пока работают `field_map` из раздела 8 и встроенные алиасы. Если колонка называется иначе, достаточно поправить конфиг, код менять не нужно.
- InfoWatch отнесен к `media`: в приложении 1 он стоит среди новостных сайтов. Вендоры только последние пять строк: Positive Technologies, Солар, Лаборатория Касперского, UserGate, ИнфоТеКС.
- Хабр и страницы `ixbt.com/live/` отнесены к `author`. Остальной iXBT считается `media`.
- Регуляторов в приложении 1 нет. По именам и доменам распознаются ФСТЭК, ФСБ, Роскомнадзор, Минцифры, НКЦКИ, ГосСОПКА, Банк России и ЦБ РФ. Остальные неизвестные источники остаются `unknown`.

## Передачи второму участнику

- Учебный набор для всех следующих этапов: `testdata/synthetic/articles.json`. Контрольное время `2026-11-07T12:00:00+03:00`. Какая запись зачем, написано в `testdata/synthetic/README.md`.
- Перед промптом берите `normalize.Apply`: в модель идет очищенный `Text`, исходник остается в `RawText`. Длинный текст режется через `normalize.Chunks`.
- Ошибки чтения уже лежат в журнале загрузчика. Раннер должен перенести эти строки в итоговый журнал и не затирать их.
- Статья с непустым `ReadError` уже исключена. Повторно не классифицировать.
- `SourceKind` считается в `ingest.SourceKindOf`. Отдельный вызов модели для вида источника на известных площадках не нужен.
- Трудные файлы лежат в `testdata/hard/`. Загрузка их не роняет: пустые и битые становятся записями журнала.
